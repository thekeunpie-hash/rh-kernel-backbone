The Lean proof of the Riemann Hypothesis, for readers and contributors

leanprover-community/riemann-hypothesis is the community repository for a Lean 4 formalization of the 2026 proofs of the Riemann Hypothesis and of GRH for Dirichlet L-functions. This site explains how to read that proof and how to send a pull request to it, and it keeps a dated record of what the repository has done.

One thing to know before anything else. The proof has been checked by machine and by nobody else yet. The README of lsernau/grh-lean, the edition upstream main is based on, says it in these words: “The proof has passed machine checks only … No mathematician has read it through, and no paper comes with it.” The work that is open to contributors is therefore work on the code: making it faster to build, easier to read, and better connected to Mathlib and to the literature.

    About this site

    This is an independent site. It is not written or endorsed by the maintainers of the upstream repository. A number on it names the commit it was measured at and who measured it, whether that is upstream’s own README, a published verification record, or this site’s scripts. Where a figure is this site’s own measurement and cannot be reproduced from a public source, the page says so.

    Upstream’s README asks contributors for three things: a proof that is accessible (builds without large amounts of compute), readable (code quality moving toward Mathlib’s), and integrated with the community (references to prior work, reuse of existing formalization projects). It also names what it does not want: reports of your own machine’s builds or comparator runs, and files the proof does not need. Read the README before you start; it is short and it is the authority.
